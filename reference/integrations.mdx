# Integrations

k6 integrates with a wide ecosystem of tools for monitoring, visualization, CI/CD, and more.

## CI/CD platforms

### GitHub Actions

Use the official k6 action:

```yaml
name: Load Test
on: [push]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: grafana/k6-action@v0.3.1
        with:
          filename: test.js
          flags: --vus 50 --duration 10s
```

### GitLab CI

```yaml
load_test:
  image: grafana/k6:latest
  script:
    - k6 run test.js
  artifacts:
    reports:
      junit: summary.xml
```

### Jenkins

```groovy
pipeline {
  agent any
  stages {
    stage('Load Test') {
      steps {
        sh 'k6 run --out json=results.json test.js'
      }
    }
  }
}
```

### CircleCI

```yaml
version: 2.1
jobs:
  load-test:
    docker:
      - image: grafana/k6:latest
    steps:
      - checkout
      - run: k6 run test.js
```

## Cloud platforms

### Grafana Cloud k6

Run tests in the cloud with built-in dashboards and insights:

```bash
k6 cloud script.js
```

[Learn more about Grafana Cloud k6](/cloud/overview)

### AWS

- Run k6 on EC2 instances for distributed testing
- Use AWS Lambda with k6 for serverless testing
- Store results in CloudWatch or S3

### Azure

- Deploy k6 using Azure Container Instances
- Use Azure Load Testing (powered by k6)
- Stream metrics to Azure Monitor

### Google Cloud

- Run k6 on GKE (Google Kubernetes Engine)
- Use Cloud Run for serverless k6 tests
- Export metrics to Cloud Monitoring

## Test data and mocking

<AccordionGroup>
  <Accordion title="Faker.js">
    Generate realistic test data:

    ```javascript
    import { Faker } from 'https://esm.sh/@faker-js/faker';

    const faker = new Faker();

    export default function () {
      const user = {
        name: faker.person.fullName(),
        email: faker.internet.email(),
      };
    }
    ```
  </Accordion>

  <Accordion title="JSON Server">
    Mock REST APIs for testing:

    ```bash
    # Start mock server
    json-server --watch db.json

    # Test against it
    k6 run test.js
    ```
  </Accordion>

  <Accordion title="WireMock">
    Stub HTTP services:

    ```javascript
    import http from 'k6/http';

    export default function () {
      http.get('http://localhost:8080/api/users');
    }
    ```
  </Accordion>
</AccordionGroup>

## Reporting

### HTML reports

Generate HTML reports from k6 results:

```bash
k6 run --out json=results.json script.js
k6-reporter results.json
```

### JUnit reports

For CI/CD integration:

```javascript
import { jUnit, textSummary } from 'https://jslib.k6.io/k6-summary/0.0.1/index.js';

export function handleSummary(data) {
  return {
    'stdout': textSummary(data, { indent: ' ', enableColors: true }),
    'summary.xml': jUnit(data),
  };
}
```

### CSV/JSON export

Export metrics to files:

```bash
k6 run --out csv=results.csv script.js
k6 run --out json=results.json script.js
```
